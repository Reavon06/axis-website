# Deployment & viewing

## View on your computer (no install)

Double-click **`index.html`** in this folder. No npm, Node, or `npx serve` required.

Upload the whole **`axis-3d-website-html`** folder to any static host (Netlify, cPanel, S3, etc.) if you want it online.

## Upload contents

- `index.html`, `works/`, `about/`, `contact/`
- `assets/` (css, js, images)
- `favicon.svg`

## Server notes

On a web server, `/works/` can map to `works/index.html` automatically. When opening files locally, use the site’s nav links between pages.

## Checks after upload

1. Home page 3D hero animates
2. All nav links work
3. Mobile menu opens
4. WhatsApp button works on phone
